Privacy

Spookky keeps workspace metadata on your Mac. It does not require a Spookky account.

The app

Workspace folders, conversation titles, launch drafts, browser tab addresses, and process references are stored locally. Spookky reads local provider history to list and reopen conversations. Terminal contents stay in the terminal stack. Spookky does not operate a service that receives your prompts, source files, or terminal output.

Your shell, Git commands, and agent CLIs may communicate with services you choose. Their authentication, permissions, histories, and privacy policies remain their own.

GitHub features

Project avatars are requested from GitHub using the owner name in a project's GitHub remote. Avatar images are cached on your Mac. GitHub and its image host receive the owner name and ordinary connection information, including your IP address.

Pull-request status uses your installed GitHub CLI and its existing authentication. These lookups send the repository and branch information needed to identify a pull request to GitHub. Spookky does not operate a proxy for these requests.

Browser tabs

The embedded browser connects to the websites you open. Those sites can receive your IP address and any information you submit, and can store cookies and other website data on your Mac. Browser tabs share Spookky's WebKit website-data store. Closing a tab does not clear that data.

Text submitted as a search from New tab is sent to DuckDuckGo. Each website's own privacy policy applies.

Updates

A public signed installer is not available yet. The signed-build update integration uses Sparkle. If you enable update checks in such a build, the app requests the release feed from GitHub Pages and downloads selected updates from GitHub Releases. These requests reveal ordinary connection information, including your IP address, to the hosting providers. Spookky does not send a system profile. You can change automatic checks and downloads in Settings.

This website

There are no added analytics, advertising scripts, or tracking cookies. The site follows your system color theme and does not store preferences in your browser. GitHub Pages hosts the site and may log connection information for security and service operation. Source and installer downloads also connect to GitHub. See GitHub's privacy statement.

Reports you submit

GitHub issues and pull requests are public. Remove private paths, prompts, credentials, and terminal content before sharing diagnostics. Report vulnerabilities through GitHub's private reporting channel.
