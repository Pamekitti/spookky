Privacy

Spookky keeps workspace metadata on your Mac. It does not require a Spookky account.

The app

Workspace folders, tab names, launch drafts, and process references are stored locally. Terminal contents stay in the terminal stack. Spookky does not operate a service that receives your prompts, source files, or terminal output.

Your shell, Git commands, and agent CLIs may communicate with services you choose. Their authentication, permissions, histories, and privacy policies remain their own.

Updates

Signed public builds use Sparkle. If you enable update checks, the app requests the release feed from GitHub Pages and downloads selected updates from GitHub Releases. These requests reveal ordinary connection information, including your IP address, to the hosting providers. Spookky does not send a system profile. You can change automatic checks and downloads in Settings.

This website

There are no added analytics, advertising scripts, or tracking cookies. The site follows your system color theme and does not store preferences in your browser. GitHub Pages hosts the site and may log connection information for security and service operation. See GitHub’s privacy statement.

Reports you submit

GitHub issues and discussions are public. Remove private paths, prompts, credentials, and terminal content before sharing diagnostics. Report vulnerabilities through GitHub’s private reporting channel.
