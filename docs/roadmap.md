# Roadmap

## Public Preview

Deliver a signed, notarized drag-to-Applications installer for Apple Silicon. Verify fresh installation and an update between two signed releases. Publish current limitations with each release.

## Stable

Resolve extended continuity failures. Complete hands-on typing, IME, VoiceOver, provider resume, sleep/wake, reboot, supported macOS, and resource checks. Each gate needs evidence from the native app.

## After Stable

Prepare a Homebrew cask. Consider wider architecture support, translations, and additional maintainers when testing and maintenance capacity support them. There are no promised dates.
