# Spookky 0.1.2

This private preview retains native text selection after mouse release. Cmd+C uses Ghostty's selected text. Programs that request mouse input retain their gestures. Scrolling continues through the existing runtime.

The selection decision checks the owned pane on each left click. It adds no background polling. The query has a 150 ms timeout and retains at most one press, one drag position, one release, and one clipboard action.

The header and fullscreen safeguards from 0.1.1 remain. Public signing, notarization, automatic updates, and the existing continuity gates remain pending. See [current status](../status.md) and [the release procedure](../releasing.md).
