# Spookky 0.1.3

This private preview restores final-tab closure alongside the selection and fullscreen fixes from 0.1.2.

- Closing the last tab removes its workspace.
- Closing the final tab closes the window without a replacement landing page.
- Enter confirms Close. Escape cancels and keeps the terminal focused.
- Cmd+T after final-tab closure opens one Home terminal.
- First use retains the Home start screen with Terminal selected.
- Reopening after all workspaces were closed shows the Home start screen.

The local DMG is verified and installed on the maintainer's Mac. The installed app reopened on the Home start screen. Automated native checks cover closure, Enter/Escape, reopening, and retained selection. The maintainer confirmed the physical close-tab and Cmd+T reopening checks on 13 October 2026. Text selection, Cmd+C, and fullscreen continue to work.

Closing a workspace retains its files and branch. Apple signing, automatic updates, and continuity acceptance remain separate gates.
