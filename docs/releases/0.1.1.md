# Spookky 0.1.1

This private preview stops terminal gestures from moving the window. The maintainer reports that the selection highlight still disappears after release. Version 0.1.2 addresses that remaining issue. Public signing, notarization, and automatic update delivery remain pending.

- Terminal dragging stays inside the terminal.
- Only unused header and tab-strip areas move the normal window.
- Fullscreen and its transitions disable header dragging.
- Fullscreen exit restores header dragging and normal window geometry.

The existing continuity and native acceptance gates remain separate. See [current status](../status.md) and [the release procedure](../releasing.md).
