# Spookky 0.1.0 Preview 1

Draft notes. This release is not published. Signed installation, real update delivery, and supported-OS checks must pass before publication.

## Included

- A native Mac workspace around Ghostty's terminal core.
- Shells, terminal tabs, splits, optional projects and worktrees, files, and diffs.
- A bundled terminal runtime and separate installed-app storage.
- Native Settings, About, license notices, and Sparkle update integration.
- MIT-licensed original code, documentation, and artwork.

## Current limits

Extended continuity, physical typing and IME, spoken VoiceOver, provider responses and resume, sleep/wake, reboot, and supported macOS versions have remaining checks. The earlier eight-hour run lost its original panes; its cause remains unresolved.

App restart and surviving-process reattachment do not guarantee recovery after an inner process ends or the Mac reboots. Unknown process activity remains unknown.

## Publication evidence

Before publishing, record the tested source commit, final installer SHA-256, build number, tested OS/architecture, and signed installation/update results. Keep raw logs and session contents private. Use [the release procedure](../releasing.md).
