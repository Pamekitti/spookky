# Spookky 0.1.4

Build 104 is a source prerelease and private local app update for Apple Silicon. Public signed installers and automatic updates remain unavailable.

## Changes

- Give new workspaces readable names and derive their title from the first starting prompt. Manual names take precedence.
- Show CLI agent activity and unread completions in tabs and workspace rows. Add notification preferences and optional sounds.
- Preserve normal Codex hook trust, provider permissions, and existing hook sources. The callback command remains stable across invocations.
- Migrate naming and activity metadata to version 5 with a backup. Retain drafts, bindings, manual names, and unread completions from earlier development snapshots.
- Fix clipped diffs when switching from a modified file to an added file and back.
- Update pinned GitHub Actions and the website's Playwright test dependency.

## Verification

The combined app passed 111 XCTest cases, 17 Swift Testing cases, 30 Python tests, 12 callback fixtures, 27 native sidebar checks, and 24 native diff checks. The diff fixture completed 100 selection cycles. Selected preview p95 was 106.6 ms across 30 samples on macOS 26.6.2. This measures native layout readiness and excludes physical display latency.

Short resource observations covered 1, 5, and 10 shells with simulated activity. All six observations retained their process sets. At 10 shells with activity, app RSS was 143.8 MiB and total session RSS was 182.1 MiB. These five-second observations exclude real provider workloads and do not establish long-term performance.

The native Release build, bundle audit, and public source/history audit passed. Each merged PR must pass its required GitHub checks against current main.

## Installation and limits

The private local installer uses an ad hoc signature and keeps automatic updates disabled. It is retained on the maintainer's Mac and is not attached to this public release. Existing workspace metadata and the previous app are backed up before local replacement.

Codex activity hooks require normal provider trust review. Until approved, activity may remain unknown. Interactive hook approval, native banners, sounds, notification click-through, older supported-OS claims, extended continuity, sleep/reboot, and spoken VoiceOver remain manual acceptance work. A completed agent turn does not prove task success.

Developer ID signing credentials are not configured. This release contains source archives only. Public notarized app delivery remains blocked on Apple signing and installation/update acceptance.
